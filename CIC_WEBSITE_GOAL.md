# CIC Website Goal

Goal: make the site credible as a complete CIC organization website, not only a launch brochure.

## Core Website Standard

- Clear mission, story, promise and public benefit.
- Practical pages for community, events, members, blog, joining and partners.
- Member visibility that protects private data and publishes only approved profiles.
- Admin tools for join requests, member profiles and blog updates.
- Impact and governance page for public benefit, accountability and responsible referrals.
- Deployable infrastructure and CI/CD for a small Azure-hosted frontend.

## Current Build

- Public pages: home, community, events, join, blog, members, impact.
- Backend: Convex tables and HTTP APIs for admin sessions, join requests, members and blog posts.
- Admin panel: review join requests, promote requests into draft member profiles, manage members, publish blog posts.
- Hosting: Azure Static Web App with GitHub Actions.

## Next CIC Completion Items

- Add privacy, safeguarding and complaints policy pages.
- Add annual impact report uploads or impact posts.
- Add director/team governance profiles when confirmed.
- Add partner logo/testimonial management.
- Add member consent fields and optional profile photo storage.
